3. HIGH — os.system() inside a signal handler
runAUTO.py:164


os.system("sh -c '%s'"%command)
Signal handlers must only call async-signal-safe functions. os.system() is not async-safe — it can deadlock if the signal fires while Python holds internal locks (e.g. the GIL, malloc). Also, command is formatted from /bin/kill -KILL <pid> where pid is parsed from raw ps ww output; a process with a crafted name could inject shell metacharacters past the single-quote boundary.
